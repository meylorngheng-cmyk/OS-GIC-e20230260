5. What is /proc?
/proc is a virtual filesystem in Linux. It provides information about running processes and the operating system. Files such as /proc/cpuinfo and /proc/meminfo provide CPU and memory information.

6. What is the purpose of the operating system?
The operating system manages hardware and software resources. It provides services for programs, manages memory and processes, and controls access to devices and files.

7. Basic OS Layers
- User applications: Programs used by people.
- System call interface: Allows applications to request services from the kernel.
- Kernel: Manages processes, memory, files, devices, and system resources.
- Hardware: CPU, RAM, storage, and other physical devices.
